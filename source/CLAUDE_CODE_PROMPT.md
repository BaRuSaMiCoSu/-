# Claude Code への依頼

このフォルダの `questions.md`（問題49〜89の全文・正解・解説）と `figures/*.svg`（問題の図）を使って、高校「情報Ⅰ」の一問一答サイトを作ってください。

## 仕様
- 静的サイト（index.html＋必要ならJS/CSS）。ビルド不要でブラウザで開けば動くこと
- まず `questions.md` を読み、全問を `questions.json` などのデータに変換する。小問（52-1、85-A など）は1問ずつ別カードにする。文言は変えず、1問も省略しない
- スマホ優先。1画面に1問のカード形式
- 選択肢がある問題はボタンで回答し、正誤をすぐ表示する。70は複数選択、89-2・56は複数空欄に対応する
- 記述・数値の問題は「答えを見る」で正解を表示し、「正解した／まちがえた」を自己申告する
- 回答後に解説を表示し、「次へ」で進む
- 図がある問題（57, 61, 68, 78, 85, 89）は対応するSVGを問題文の下に表示する
- 出題順は「順番」「ランダム」を切り替え可能。範囲は「全問」「基本問題」「発展問題」、または問題番号で絞り込み
- 最後に正答率を表示し、まちがえた問題だけ解き直せる
- 正誤の記録は localStorage に保存し、使えない環境でも動くよう try/catch で囲む
- ダークモード時もSVGが読めるよう、図は白背景のカードに載せる
